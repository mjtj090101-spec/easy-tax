# 쉽게보는 세금

세금 신고·납부 기한을 놓치지 않도록 달력과 '곧 해야 할 일' 목록으로 보여 주고, 신고마다 체크리스트로 챙기는 웹 페이지입니다. 경기도 화성시 동탄의 기관을 기준으로 만들었습니다.

## 쓰는 법

`index.html`을 더블클릭하면 브라우저에서 열립니다. 설치할 것은 없습니다.

- **곧 해야 할 일:** 기한이 지났거나 7일 안에 마감되는 일정
- **세금 현황:** 9가지 세금의 주기, 신고처, 다음 기한, 진행률. 우리 기관에 해당하지 않는 세금은 '해당'을 끕니다.
- **관할 기관:** 동화성세무서(국세)와 동탄구청 세무과(지방세)
- **달력:** 일정을 누르면 체크리스트, 담당 부서 전화번호, 신고하는 방법이 나옵니다.

체크 상태와 메모는 쓰고 있는 브라우저에만 저장됩니다.

## 고치는 법

일정, 체크리스트, 담당 부서는 모두 `data.js`에 있습니다. 해가 바뀌면 이 파일만 고치면 됩니다. 기획 내용은 `PRD.md`에 있습니다.

## 주의

`data.js`의 일정은 예시입니다. 실제로 쓰기 전에 홈택스·위택스 세무일정과 대조하세요. 관할 기관 전화번호는 2026년 11월에 각 기관 홈페이지에서 확인한 값입니다.
